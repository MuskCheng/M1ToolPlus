本次发布是围绕界面的一次集中整改：窗口尺寸、主题配色、控件观感、文案与文档统一收口，读写卡的业务逻辑与 v1.8.0 保持一致。

### 界面

- 窗口尺寸固定为 787×787，打开即完整布局，不必再手动拉伸
- 新增深色 / 浅色 / 跟随系统三档主题，整窗自绘圆角与边框，状态栏、下拉菜单、输入框同步换色
- 卡片区维持 1:1 方块排布；字号、颜色块、数字输入框统一为 76×21 的横条并右缘齐平
- 终端日志区支持拖拽调整高度，默认比例更偏向日志
- 修掉一批细碎瑕疵：下拉箭头、数字框边框、状态栏文字颜色、组标题换行等

### 精简

- 只保留简体中文界面，移除英文 / 俄文资源与语言选择入口
- 中性资源与中文卫星资源同步，语言回退不再随系统区域变化而出现中英混排

### 文档

- README 重构：本地徽章（不依赖 shields.io）、实机截图、功能与工具矩阵、常见问题
- 新增 DEVELOPMENT 中的发版流程与 `nfc-bin` 依赖还原说明

### 更新包校验

下载 `M1ToolPlus-v1.8.1.zip` 后可与 `SHA256SUMS.txt` 核对：

```
certutil -hashfile M1ToolPlus-v1.8.1.zip SHA256
```

程序内的「检查更新」同样会比对 GitHub 附件的 SHA256，校验不通过不会解压覆盖现有文件。

### 依赖

`nfc-bin\` 内的 libnfc、mfoc、mfcuk 等工具不入版本库，由发版流水线从上游 `xcicode/MifareOneTool v1.7.0` 的 Release 资产自动还原后打进包里，解压即用。

### 已知限制

- 需要 .NET Framework 4.0 运行时（Windows 10 / 11 已内置）
- ACR122 开关会真实改写 `nfc-bin\libnfc.dll`，因此不提供单文件打包形式
