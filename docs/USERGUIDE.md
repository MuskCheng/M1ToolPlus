> 本文档改写自原作者 XciCode 的《M1T 应用手册》v1.6.4（随 MifareOneTool 发布，GPL-3.0，原版权 © XciCode 保留），已按本衍生版 **M1ToolPlus v1.8.0** 修改与增补。变更点：程序名与仓库链接、新增功能章节（主题/语言/终端/检查更新/MFF08 救砖）、支持渠道指向本仓库。原版全文存档见 [原作者仓库](https://github.com/xcicode/MifareOneTool)。

## 1 简介

M1ToolPlus（简称 M1TP）是基于 libnfc 的 Mifare Classic（M1 卡）Windows 图形化操作工具，是 [MifareOneTool](https://github.com/xcicode/MifareOneTool) 的社区延续版，GPL-3.0 开源。

> ⚠️ 本软件部分功能具有**攻击性**（密钥破解、卡数据读写），请仅用于你有授权的卡片，勿违法使用！因使用本软件造成的任何后果由使用者自行承担。

主界面包含三个页签：

| 页签 | 说明 |
|---|---|
| **复制卡模式** | 向导式流程：检测 → 扫描 → 解密 → 读 → 写，按钮按操作顺序排布 |
| **高级操作模式** | 全部功能按钮的完整集合，适合熟悉流程的用户 |
| **软件设置** | 语言/主题、终端外观、设备参数与常用开关 |

同一功能在两个模式下按钮名称不同，本文档按 **「高级名称 复制卡名称」** 的格式列出（与原手册一致）。状态栏右下角为**检查更新**按钮。

## 2 支持的设备及卡片

| 读卡器 | 说明 |
|---|---|
| **PN532（串口）** | 推荐。串口转接线建议使用 **CH340** 芯片；部分 PL2303 在某些系统下不稳定，CP2104 无法正常工作 |
| **ACR122U（USB）** | 支持尚不完善，**默认关闭**，需在设置中手动启用（启用后部分操作会变慢）。可自行安装 libusb 类驱动（本包不随附驱动） |

## 3 软件功能及介绍

（格式：**高级模式名称** = 复制卡模式名称；复制卡模式没有列出的即两处同名。）

### 找卡与连接

- **◆ 检测设备 检测连接**：检测是否已连接支持的 NFC 设备，结果在终端显示区输出。
- **◆ 手动扫描 扫描卡片**：扫描可读取的卡片并显示 UID、SAK、是否为后门卡（UID 卡）等信息。
- **◆ 手动 CLI**：打开 NFC 命令行（定位到 `nfc-bin\`），可自行调用工具、加自定义参数。

### 普通卡读写

- **◆ 读 M1 已知密钥读**：读取 M1 卡（可能需要先加载密钥文件）。
- **◆ 写 M1 写入普通卡**：写入 M1 卡（可能需要先加载密钥文件）。
- **◆ 清 M1**：清空 M1 卡（需要密钥文件）。
  > 注：使用「自动判断 Key」时可能出现清卡只清除了控制位、Key 未清的情况。此时取消勾选「自动判断 Key」重新执行清 M1，询问 KeyABN 时选「是」。
- **◆ 选择 key.mfd 加载密钥…**：选择一个带目标卡 Key 及正确控制位的 MFD 卡数据文件作为密钥文件。

### 魔改卡（UID 族）

- **◆ UID 读 从 UID 卡读回**：读取 UID 类特殊卡，无视 Key 与控制位。
- **◆ UID 写 写(UF)UID 卡**：写入 UID 类特殊卡，无视 Key 与控制位。
- **◆ UID 重置**：重置 UID 卡的 0 块，写入随机卡号与复旦卡厂商号。
- **◆ UID 写号**：把 0 块写为指定卡号与复旦卡厂商号。
- **◆ UID 全格**：无条件擦除 UID 卡全卡恢复空白状态；**卡数据写错导致无法访问时可用此功能急救**。
- **◆ 锁 UFUID 锁 UFUID 卡**：锁定 UFUID 卡使其变为普通 M1 卡。
  > 本功能为测试功能，锁定后请检查是否锁死！若有错误请报告。
- **◆ CUID 写 写 C/FUID 卡**：写入 CUID 卡（可能需要选择密钥文件）。

### 救砖：MFF08 CUID 修复（本版新增）

写卡失败把卡的 **0 块（UID 块）写坏**后卡会变砖（读卡器认不出、密钥校验失效）。点状态栏上方功能区的「**MFF08 CUID 修复**」打开对话框，可将出厂空白数据**直写回 0 块**救活卡片：

- **方式 A**：卡仍是全 F 出厂密钥时，直接写回内置空白数据；
- **方式 C**：用「最后一次把卡写坏时保存的 dump」里的密钥写回。

两种方式都仅对可写 0 块的魔改卡有效。修复后建议重新「手动扫描」确认卡可被识别。

### 密钥破解

- **◆ MFOC 读 一键解原卡**：对卡片执行 Nested 解密，**仅半加密卡**支持。
- **◆ 检加密 检测加密**：检测卡片的加密及默认密码使用情况。
- **◆ 知 n 密 知一密破解**：已知一个或多个有效 Key 时，尝试 Nested 解密。
- **◆ 字典测试**：用字典中的 Key 尝试 Nested 解密；解密完成后请手动关闭 cmd 窗口。
- **◆ 全加密爆破**：对卡执行 Darkside 攻击尝试取得 Key。
  > 注：可能存在小问题，对部分卡（尤其国产全加密卡）得不到正确结果；该类卡建议用嗅探方法或 Proxmark3 解密。
- **◆ HardNested**：针对「不受 Nested 攻击」的卡（如 M1-EV1、CPU 模拟卡）进行 Hardnested 解密（加强版 Nested），仅半加密卡支持。

### 通用开关与工具

- **◆ 自动判断 Key**（测试功能）：已加载 key.mfd 时按文件中的 Key 与控制位自动认证，可应对混合访问控制的情况；工作不正常请取消勾选并报告。
- **◆ 自动加载 uid.Key 文件**（测试功能）：在程序目录 `auto_keys\` 中搜索以目标卡小写 UID 开头的 MFD 文件并自动加载为 key.mfd。
- **◆ 数据写入保护**：写入前做逻辑检查，防止把错误的 BCC/访问控制位写进卡造成损坏。**仅支持 S50 卡数据文件**，写其他种类数据文件时需关闭。
- **◆ 自动以 UID 名保存文件**：把读出的文件以「小写 UID+日期时间」格式保存到 `auto_keys\`。
- **◆ 清终端** / **◆ 存日志** / **◆ 停运行**：清空终端；把终端内容保存为程序目录 `m1t.log`；强行停止正在运行的功能。
- **◆ 差异比较**：打开差异比较器（DiffTool），对比两份卡数据的扇区差异。
- **◆ Hex 编辑器**：打开卡数据文件编辑器（S50HTool）。

## 4 界面与设置（本版增强）

### 外观与语言

- **主题**（设置页「外观/主题」）：**跟随系统 / 深色 / 浅色**，切换立即生效，配置/差异比较/Hex 编辑/修复等子窗口同步换色，重启后保持。
- **界面语言**：简体中文（默认）/ Русский / English，选择后自动重启生效。
- **终端字体**：字体族与字号在设置页统一管理（**默认 12pt**，比界面字号大一号）；终端内 **Ctrl+滚轮** 可直接缩放，与设置页数值联动。终端配色用 `#M1T#` 按钮调整。
- **高 DPI**：100% / 125% / 150% 缩放下窗口 1:1、文字清晰；主窗口固定大小不可拖拽。

### 软件设置页常用开关

| 开关 | 说明 |
|---|---|
| 多实例运行模式 | 允许多开并禁用单实例检测，**需自行指定设备** |
| 减少找设备延迟 | 扫描/找卡时等待更久，降低漏检 |
| 自动转到高级操作模式 | 启动后直接进入高级操作模式页签 |
| 单线程计算 | Hardnested 用单线程计算（低配机器不卡界面） |
| 终端颜色 / 字号 | 见上文「终端字体」 |
| 设备参数 | 形如 `pn532_uart:COM6:115200`，留空自动识别 |

### 检查更新（本版新增）

点状态栏右侧的「**检查更新**」：

1. 程序查询本仓库最新 Release 并自动对比版本；
2. 有新版本时**直接弹出下载进度条**（来源为 GitHub，无第三方渠道）；
3. 下载完成后二选一：
   - **继续使用**：留在当前版本，更新包保留在临时目录（同版本不重复下载）；
   - **重启更新**：程序退出 → 自动解压覆盖安装目录 → 自动重启到新版本；
4. 检查失败可「重试」或「打开发布页」手动下载。

> 更新**不会丢失设置**：语言、主题、终端字号、设备参数等会随版本自动迁移。

## 5 内置编辑器（S50HTool）

M1ToolPlus 集成 MFD 文件 HEX 编辑器（S50HTool），用于卡数据文件编辑。

> ⚠️ 手误关闭**不会**提示文件未保存！

菜单（全部配有快捷键）：

- **文件**：新建 / 打开 / 保存 / 另存为（Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S）
- **工具**
  - **修改 UID**（Ctrl+U）：转到 0 块编辑模式修改 UID（自动更正 BCC）
  - **检查全卡**：检查卡片数据是否存在逻辑错误
  - **检查全卡并纠正**：检查并自动修正
  - **导入 MCT 格式** / **导出为 MCT 格式**：与手机端 MCT 互通
  - **导出密钥字典**：把该卡的 Key 以字典形式导出（兼容 MCT 格式）

单击「扇区列表」中的扇区可跳转编辑；点「修改扇区」把改动**验证并保存到当前工作区**（注意不是保存到打开的文件）。

## 6 入门操作（复制卡模式）

以复制一张卡为例：

1. 从 [Releases](https://github.com/MuskCheng/M1ToolPlus/releases/latest) 下载最新包，解压到独立目录（建议路径不含空格），双击 `M1ToolPlus.exe` 运行。
2. 依次点 **检测连接 → 扫描卡片 → 检测加密**。若检测加密结果中所有 Key 都未知，很可能无法解密。
3. 保持卡与读写器通信良好，点 **半加密破解**（= 高级模式「MFOC 读」）解密；成功后保存卡数据文件（MFD）。
   - 已知一个或多个 Key 时，点 **知一密破解** 输入以加快速度。
4. 取下原卡，换上空白卡，点对应写卡按钮：
   - 询问 KeyABN 时点「**取消**」；
   - UFUID 卡写入后需要「锁 Ufuid」。
5. 测试复制出的卡是否正常使用。

## 7 基本操作流程

### 1) 读取原卡

> ⚠️ 本工具**无法一键解密 SAK=28** 的卡，只能已知密钥读写，建议配合手机端 MCT。

1. 连接设备，点「检测设备」。检测不到时检查设备管理器里有没有设备、接线是否正确。
2. 放上原卡，点「手动扫描」。
   - 观察 SAK，目前支持 08/18/28；
   - 扫不到换个姿势与天线通信；仍无反应多半是不支持的卡型。
3. 点「MFOC 读」尝试解密。
   - 提示全加密卡 → 须先通过其它方式获得一个有效 Key；
   - SAK=28 或提示不受 Nested 攻击 → 试「Hardnested」；
   - 已有该卡数据文件 → 「选择 key.mfd」加载后用「读 M1」读出。
4. 保存读出的卡数据文件。

### 2) 写入卡片

- 目标卡为**非空卡**：加载该卡原数据文件为 key.mfd → 「写 M1」选数据文件写入。
- 目标卡为 **M1 白卡**：「写 M1」选数据文件写入；询问 KeyABN 选「取消」。
- 目标卡为 **UID/UFUID 卡**：「UID 写」选数据文件写入；UFUID 卡写完再点「锁 Ufuid」。
- 目标卡为 **CUID/FUID 白卡**：「CUID 写」选数据文件写入；询问 KeyABN 选「取消」。

## 8 附：手机/手环模拟卡实战

1. 连接 NFC 设备，点「检测设备」确认能找到设备。
2. 放上原卡，点「手动扫描」，确认原卡 SAK 为 08/28。
3. 按 §7.1 读取原卡数据。
4. 制作一张与原卡 **UID 相同**的白卡（UID 或 CUID 二选一）：
   - **UID 白卡**：扫描原卡记下 8 位 UID → 放上 UID 卡 → 「UID 写号」粘贴 UID（去掉空格，必须正好 8 位字符，如 `1eec44ef`）。
   - **CUID 白卡**：
     1. 扫描原卡记下 8 位 UID；
     2. 「Hex 编辑器」→ 文件-新建（Ctrl+N）→ 工具-修改 UID（Ctrl+U）粘贴 8 位 UID → 文件-另存为（Ctrl+Shift+S）保存**仅含卡号**的数据文件；
     3. 放上 CUID 卡 → 「CUID 写」选该文件；询问 KeyABN 选「取消」。
5. 用手机/手环模拟这张白卡：调起刷卡模式，贴在 NFC 设备上。
6. 点「写 M1」选择**原卡数据文件**写入；询问 KeyABN 选「取消」。
7. 测试模拟卡是否正常。

> 手环调起刷卡的时间窗口太小来不及操作时：可先做第 6 步，再调起刷卡放上设备——软件会等待卡片，检测到后自动继续。
